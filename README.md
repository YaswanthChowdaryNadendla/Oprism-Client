# Oprism – The Signature of Purity 💧

**Pure by Nature. Premium by Choice.**

Oprism is a premium bottled-water brand website designed to showcase hydration solutions for everyday needs, celebrations, weddings, corporate events, and special occasions.

The website combines a clean visual identity, modern animations, responsive layouts, and convenient customer enquiry through WhatsApp.

## ✨ Features

- **Premium Homepage** – Brand introduction with cinematic visuals and animations.
- **About Oprism** – Brand story, values, and commitment to quality.
- **Services** – Explore customized bottled-water solutions, event supplies, and bulk orders.
- **Contact & Enquiries** – Submit enquiries through an interactive contact form.
- **WhatsApp Integration** – Send enquiry details directly through WhatsApp with prefilled messages.
- **Responsive Design** – Optimized for desktop, tablet, and mobile devices.
- **Modern Animations** – Shutter text reveals, scroll-based animations, sliding numbers, and interactive transitions.
- **Custom Branding** – Oprism logo, favicon, visual assets, and brand-focused design.

## 🚀 Getting Started

### Prerequisites

- Node.js 20 or later
- npm
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/oprism.git
```

### 2. Navigate to the Project

```bash
cd oprism
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start Development Server

```bash
npm run dev
```

Open the local development URL displayed in your terminal.

### 5. Build for Production

```bash
npm run build
```

### 6. Preview Production Build

```bash
npm run preview
```

## ☁️ Deployment

The project is configured for deployment on **Vercel**.

Recommended settings:

- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`
- Install Command: `npm install`

The `vercel.json` configuration supports client-side routing and direct access to website pages.
